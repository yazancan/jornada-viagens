# Jornada Viagens

Projeto de site de viagens desenvolvido durante a formação de front-end da Alura, com foco na criação de páginas completas e organização de conteúdo.

## 🚀 Tecnologias
- HTML
- CSS

## 💡 Funcionalidades
- Página inicial com apresentação do site
- Seção de pacotes de viagem
- Blog com conteúdos informativos
- Página de contato

## 🧠 Aprendizados
- Estruturação de páginas completas
- Organização de múltiplas seções em um mesmo projeto
- Estilização e layout com CSS

## ✨ Destaque
A seção de pacotes de viagem foi desenvolvida com autonomia, com posterior validação.

As páginas de blog e contato foram criadas de forma totalmente independente, sem acompanhamento direto, reforçando minha capacidade de aplicar os conhecimentos na prática.
